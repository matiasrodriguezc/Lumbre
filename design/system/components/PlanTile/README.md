# PlanTile
Opción de plan en el paywall (mensual / anual).

- El consumidor provee: nombre del plan, precio localizado que devuelve la tienda (nunca hardcodeado), período, ahorro y si es el recomendado.
- Recomendado: borde 2px `pro` + badge `pro`/`on-pro`. El resto: borde `border-strong`.
- Debajo del paywall, siempre: "Restaurar compras", términos y privacidad, y cómo cancelar. Requisito de App Store y Google Play.
