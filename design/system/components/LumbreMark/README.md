# LumbreMark
El símbolo de marca: una neurona en facetado orgánico. No es un ícono de interfaz.

- `long` (horizontal, axón hacia la derecha): wordmark, splash y web. Mínimo 64pt de ancho.
- `compact` (axón curvado hacia abajo): espacios cuadrados como avatares, favicon y notificaciones. Mínimo 24pt.
- En `ink`. El núcleo `spark` solo en el ícono de app, el splash o cuando no hay otro rosa cerca; junto al wordmark, nunca (el punto ya es el rosa).
- iOS: `LumbreMark(.long)` en LumbreDesign. Los SVG y PNG de marca están en `logo/`.
