# Docs

- `plan-maestro.html`: plan visual. Abrir en el navegador.
- `analytics.md`: métrica norte, métricas de soporte y catálogo de eventos para iOS, Android, backend y web.
- `entrevistas/`: guía, reclutamiento y plantilla de síntesis de las 12 entrevistas de F0. En `simuladas/` está la ronda de ensayo con personas sintéticas (no es evidencia).
- `backlog.csv`: export del backlog. La fuente viva es Linear, proyecto Lumbre.
